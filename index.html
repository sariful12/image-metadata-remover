What gets removed

AI-generated label

The “AI generated” tag that tools like ChatGPT, DALL·E, Firefly and Gemini write into a file — including C2PA / Content Credentials and XMP labels — is wiped, so the image no longer carries the AI flag.

Location & camera data

GPS coordinates, camera and phone model, lens info, date and time, and the software name stored in EXIF are all stripped before you share an image anywhere.

Quality is protected

Only the data blocks around the picture are dropped. The cleaned image keeps the same width and height — PNG output is fully lossless, and JPG/WebP are saved at 100% quality, so side by side you cannot tell them apart.

How it works

  1. Add an image — the tool first scans it and shows you exactly what hidden metadata it found, including any AI label.
  2. It rebuilds the file from pixels only — the image is redrawn and saved fresh, so no EXIF, XMP, IPTC, GPS or C2PA block is carried over.
  3. Download the clean copy — same picture, same quality, no label. The original file on your device is never changed.

One honest note

This tool removes metadata stored in the file — AI labels, C2PA credentials, EXIF, GPS and software tags. Some AI services also hide an invisible watermark inside the pixels themselves (for example Google’s SynthID). That kind of watermark is part of the picture, not metadata, so no metadata remover can take it out — and any site claiming otherwise is not telling the truth. Removing metadata also does not change who owns an image or its copyright; use cleaned images responsibly.

Common questions

Will my image quality drop?

No visible drop. PNG output is fully lossless. For JPG and WebP the default quality is 100%, and the resolution never changes — the tool shows the cleaned file’s dimensions next to the original so you can check.

Does it remove the “AI generated” label from ChatGPT / DALL·E images?

Yes — the label those tools store in the file (C2PA Content Credentials and XMP metadata) is removed. The scan result on each image shows whether an AI label was found before cleaning. Invisible pixel watermarks, where a service uses them, are separate from the file label — see the honest note above.

Are my images uploaded anywhere?

No. Everything runs in your browser on your own device. You can even disconnect from the internet after the page loads and it will still work.

Is there a limit?

No limit — clean as many images as you want, free. Very large photos are handled by your device, so an older phone may take a few seconds on huge files.

Which formats are supported?

JPG, PNG and WebP — the formats AI image tools and cameras normally produce. The cleaned file keeps the same format unless you choose a different output format above.

I tap Download but nothing happens — what can I do?

Some in-app browsers block direct file downloads, so the tap appears to do nothing. On the cleaned image, tap Save via Share instead — your phone’s share sheet lets you save the image to Files, Photos or Drive. Opening this page directly in Chrome or Safari also makes the Download button work normally.
